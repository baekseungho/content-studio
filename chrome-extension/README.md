# 현재 버전 1.4.1 · 입력 중단 및 가운데 정렬 수정

1. chrome://extensions에서 다정 확장을 새로고침하고 **1.4.1**을 확인합니다.
2. 앱을 Ctrl+F5로 새로고침합니다.
3. 보관한 같은 초안을 빈 네이버 편집기에 옮겨 확인합니다. 일부가 입력된 기존 편집기는 덮어쓰지 않습니다.

- 실제 네이버에서는 정렬 메뉴와 옵션의 data-name이 같습니다. 메뉴 버튼과 가운데 정렬 옵션을 클래스·값으로 구분합니다.
- 이모지는 한글과 한 덩어리로 입력하지 않고 묶음 문자 단위로 나눕니다. 이모지 변형 표기를 정규화하고 입력 후 실제 표시를 확인합니다.
- 본문 입력 중에는 서식 메뉴를 누르지 않습니다. 글·사진 전달 완료 후 문단별 정렬·글꼴을 적용합니다.
- 입력 중 새 문단이나 텍스트 컴포넌트가 만들어져도 전체 본문 반영 결과로 확인합니다.
- 누락이 있으면 같은 글을 자동 재전송하지 않고 중단합니다. 진단의 textSync에 줄·조각 번호와 확인한 글자 수를 기록합니다. 원문 글자 자체는 진단에 넣지 않습니다.
- 이모지 정규화·커서 이동·지연 렌더·문단 재생성·사진 3장·네이버 실제 정렬 옵션 구조로 재현 검사를 수행합니다. 실계정에서의 최종 재확인은 필요합니다.

# 현재 버전 1.4.0

확장을 새로고침하고 앱을 Ctrl+F5로 새로고침합니다.
실제 사용자 진단의 정렬 드롭다운·글자 크기 코드를 반영했습니다.
감성 후기 기본값은 **가운데 정렬·바른히피·15px**입니다. 이미 입력한 글에는 **서식만 다시 적용**을 사용합니다.
서식 적용 결과와 실패 이유는 기존처럼 모두 표시합니다. 실제 네이버 재확인은 필요합니다.
앱 미리보기용 글꼴은 공식 네이버 원본이며 static/fonts/OFL.txt와 NOTICE.txt에 라이선스·출처를 함께 보관합니다.

# 현재 버전 1.3.0 · 입력·서식 진단

이번 버전은 기능 검증을 우선해 전달 코드와 실패 사유를 바로 보여 줍니다.
chrome://extensions에서 확장을 새로고침하고 **1.3.0**을 확인한 뒤 앱을 Ctrl+F5로 새로고침합니다.

- 같은 초안은 이전 입력 기록 때문에 기본적으로 재입력이 막힙니다. 앱의 **같은 글 다시 넣기**를 선택하면 빈 편집기에서 다시 시험할 수 있습니다. 1분 간격과 보호 잠금은 그대로 적용됩니다.
- **전달 코드로 직접 옮기기**로 번호를 복사하고 평소 크롬의 빈 네이버 글쓰기 탭에서 확장에 붙여 넣어도 됩니다.
- 앱과 확장에 실패 사유·중단 단계·프레임 탐색·실제 정렬·글꼴·크기·서식 메뉴 탐색 결과가 표시됩니다. **입력·서식 진단 복사**를 누르면 함께 복사됩니다.
- 글·사진이 들어가도 서식 확인이 안 되면 부분 완료로 표시합니다. 이 경우 확장의 **서식만 다시 적용**으로 글·사진 재입력 없이 재검사할 수 있습니다.
- 이미 내용이 있는 편집기에는 글·사진을 덮어쓰지 않습니다. 새 전달 코드는 같은 초안의 사용하지 않은 이전 코드를 교체합니다.
- 로그인 화면으로 이동하면 전달 정보를 유지합니다. 로그인 후 빈 편집기에서 준비한 글을 가져옵니다. 실제 코드 유효 기간은 10분입니다.
- 편집기에 전달된 결과 진단은 로컬 data/naver-extension-diagnostics.json에도 저장됩니다. 문제가 생겼을 때 이 파일로 원인을 확인할 수 있습니다.
- 진단에는 초안 본문·사진 데이터·로그인 정보·API 키·전달 코드가 포함되지 않습니다.

아래는 이전 버전의 설치 및 기본 설명입니다.

# 다정 스튜디오 크롬 확장

## 최초 설치 — 사용자가 평소 네이버에 로그인하는 크롬에서

1. 주소창에 chrome://extensions 를 입력합니다.
2. 오른쪽 위 '개발자 모드'를 켭니다.
3. '압축해제된 확장 프로그램을 로드'를 누릅니다.
4. 다음 폴더를 선택합니다. 프로젝트 전체가 아니라 manifest.json이 있는 폴더입니다.

    D:\dev\content-studio\chrome-extension

5. 크롬 도구 모음의 퍼즐 아이콘에서 '다정 스튜디오 · 네이버 글쓰기 도우미'를 고정합니다.
6. 앱 http://127.0.0.1:8787 을 Ctrl+F5로 새로고침합니다.

이 확장은 크롬 웹 스토어에 등록한 제품이 아니라 이 프로젝트의 로컬 확장입니다.
브라우저 등록은 사용자가 직접 해야 합니다. 앱의 Python 서버가 실행 중이어야 합니다.

## 평소 사용하기 · 1.2.0

설치·업데이트 후 크롬 오른쪽 위 다정 아이콘에서 **앱과 연결하기**를 한 번 누릅니다.
앱은 http://127.0.0.1:8787 주소로 열립니다. 다음부터 전달 코드를 복사할 필요가 없습니다.

1. 앱에서 사진을 고르고 간단한 메모를 적습니다.
2. **예쁘게 글 만들기**를 누르고 내용을 읽어 봅니다.
3. **블로그로 옮기기**를 누르면 평소 크롬의 네이버 글쓰기 탭이 열립니다.
4. 글과 사진을 확인하고 네이버의 **발행**을 누릅니다.

네이버 로그인이 풀렸다면 열린 네이버에서 직접 로그인한 뒤 다정 아이콘의 **준비한 글 가져오기**를 누릅니다.
입력 도중에는 탭을 직접 편집하지 마세요. 일부만 옮겨졌다면 다시 넣기 전에 기존 내용을 확인하세요.

기본 **감성 후기**는 가운데 정렬·마루 부리·16px를 네이버 서식 메뉴로 선택하고 결과를 확인합니다.
메뉴 구조가 달라 적용을 확인하지 못하면 글꼴·정렬을 직접 확인하라는 안내를 표시합니다.
앱 미리보기와 파일은 컴퓨터에 설치된 글꼴에 따라 대체 글꼴로 보일 수 있습니다.
**깔끔한 정보글**을 고르면 왼쪽 정렬·나눔고딕을 사용합니다.

코드 입력·로컬 앱 주소·입력 진단은 팝업의 **도움이 필요해요**에 있습니다.

## 보안·제한

- activeTab: 사용자가 직접 선택한 탭에 임시 접근
- blog.naver.com: 앱 버튼으로 새로 연 네이버 편집기에 글·사진·서식 전달
- externally_connectable: 확장 팝업에서 연결한 로컬 앱 출처의 요청만 수신
- scripting: 네이버 편집기 텍스트·사진 입력
- storage: 연결한 로컬 앱 출처를 보관하고, 진행 결과·전달 대기 정보는 세션에 보관
- localhost / 127.0.0.1: 로컬 앱의 일회용 전달 API 호출
- 네이버 비밀번호, 쿠키, OpenAI 키, Instagram 토큰을 읽거나 보관하지 않습니다.
- 글과 사진은 선택한 전달 코드로만 가져오고 메모리에 잠시 유지합니다.
- 자동 로그인·자동 발행·무인 예약 발행을 지원하지 않습니다.
- 이미 내용이 있는 글은 덮어쓰지 않습니다.
- 보호조치·CAPTCHA·추가 인증 감지 시 입력하지 않고 앱의 보호 잠금을 유지합니다.
- 1분 간격·같은 초안 반복 입력 제한을 유지합니다. 하루 횟수 제한은 없습니다.
- 이 방식도 네이버 계정보호조치 방지를 보장하지 않습니다.
- SmartEditor 화면 구조가 바뀌면 입력 코드 보완이 필요할 수 있습니다.
- 사진은 본문의 위치 표시를 따라 글 사이에 넣습니다. 네이버의 소제목 서식과 최종 배치는 입력 후 확인하세요.

소스가 변경됐다면 chrome://extensions 에서 확장 카드의 새로고침 버튼을 눌러 주세요.
이전 팝업과 네이버 편집기 탭도 새로 여는 편이 좋습니다.
이미 입력 중이거나 저장하지 않은 글이 있다면 먼저 네이버에서 저장하세요.

## 검증 범위

일회용 코드 만료·재사용 차단, 외부 웹 출처 요청 차단, 실제 Chromium 확장 로딩 및
앱 통신, 로컬 편집기에서 제목·본문·사진 2장 입력과 기존 글 보존·보호조치 중단을 검증했습니다.
실제 로그인된 네이버 편집기와 사진 업로드는 사용자의 크롬에서 최초 확인이 필요합니다.

## 1.0.1 입력 활성화 보완

- 단순 click 대신 pointerdown/mousedown/up 순서로 편집 영역을 활성화한 뒤 입력합니다.
- execCommand 반환값만으로 실패를 판단하지 않고 실제 반영된 텍스트를 확인합니다.
- 편집기가 계속 거부하면 contenteditable 속성을 강제로 바꾸지 않고 중단합니다.
- 확장 팝업에 제목·본문 복사 버튼을 제공하므로 해당 영역을 직접 클릭하고 Ctrl+V 할 수 있습니다.
  이 경우 사진은 네이버 사진 버튼으로 직접 추가하세요.
- 직접 복사용 제목·본문은 브라우저 세션 저장소에 최대 10분간 보관합니다.
  사진 데이터와 비밀번호·쿠키·API 키는 저장하지 않습니다.
- clipboardWrite 권한은 사용자가 복사 버튼을 눌렀을 때만 사용합니다.
- '입력 상태 진단 복사'는 편집 가능 여부·포커스 태그·노드 개수만 복사합니다.
- 재실행 간격은 사용자 요청에 따라 60초로 변경했습니다. 하루 횟수 제한은 제거했습니다.
- 업데이트 후 chrome://extensions에서 다정 확장의 새로고침 버튼을 눌러야 합니다.

## 1.0.2 iframe 입력 지원

사용자 진단(activeTag=IFRAME, titleEditable/bodyEditable=false)에 맞춰 보완했습니다.

- 표시용 제목·본문 문단과 실제 키보드 입력 문서를 구분합니다.
- 문단 클릭 후 포커스가 iframe으로 이동하면 그 안의 편집 영역과 선택 범위를 유지합니다.
- 부모 문서의 Range를 덮어쓰지 않고 입력 문서의 execCommand를 사용합니다.
- 입력 후 화면의 제목·본문에 실제로 반영되는 것을 확인합니다.
- 중첩된 동일 출처 입력 iframe도 최대 5단계까지 따라갑니다.
- 접근 불가능하거나 편집 불가능한 iframe은 강제로 활성화하지 않습니다.
- 진단에는 포커스 경로별 태그·편집 가능 여부·designMode·편집 노드 수를 추가했습니다.
  글 내용·계정 정보·URL·전달 코드·키는 포함하지 않습니다.

확장 업데이트 절차:
1. chrome://extensions 에서 다정 확장의 새로고침을 누릅니다.
2. 표시 버전이 1.0.2인지 확인합니다.
3. 기존 팝업을 닫습니다. 작성 중인 글이 있다면 먼저 저장합니다.
4. 빈 네이버 글쓰기 탭에서 새 전달 코드로 실행합니다.

실제 네이버 편집기 재확인은 필요합니다.

## 1.0.3 문단·사진 업로드 보완

- 본문을 줄 단위로 입력하고 줄 사이에 편집기의 Enter 이벤트/문단 분리 동작을 전달합니다.
- 문자를 공백 제거 후 비교하던 검사에 실제 화면 문단 수 확인을 추가했습니다.
  글자만 들어가고 문단이 합쳐지면 사진 입력 전에 중단하며 완료로 보고하지 않습니다.
- 사진 버튼은 현재 편집기뿐 아니라 접근 가능한 동일 출처 상위·형제 iframe에서도 찾습니다.
- 툴바 클릭 후 지연 생성되는 업로드 iframe/파일 입력을 기다립니다.
- image/*뿐 아니라 .jpg/.jpeg/.png 등의 accept 형식도 인식합니다.
- 사진 전용 iframe에 별도의 등록/확인 단계가 있으면 해당 문서 안에서만 확인합니다.
  블로그의 최종 발행 버튼은 누르지 않습니다.
- 새 진단에는 업로드 단계, 문서별 파일 입력 accept/multiple/disabled 상태,
  사진 버튼·iframe 개수가 추가됩니다. 파일명·내용·계정·주소는 포함하지 않습니다.
- 실제 네이버 사진 창이 다른 출처나 별도 창으로 열리면 자동 접근이 제한될 수 있습니다.
  접근 제한을 우회하지 않으며, 사진을 임의의 다른 입력에 전송하지 않습니다.

업데이트는 chrome://extensions의 확장 새로고침으로 적용합니다.
버전 1.0.3 확인 후 기존 글은 보관하고 새 빈 글쓰기 탭에서 새 전달 코드로 실행하세요.
서버·인스타그램 사진 연결은 이번 업데이트에서 재시작하지 않습니다.

## 1.1.0 사진 위치·일상 후기체

- 본문의 [[photo:1]], [[photo:2]] 순서대로 글과 사진을 번갈아 입력합니다.
- 한 번에 전부 업로드해 끝에 모으는 방식 대신 해당 위치에 사진을 한 장씩 넣습니다.
- 사진 뒤의 실제 텍스트 문단을 확인한 경우에만 다음 글 입력을 진행합니다.
- 다음 문단이나 순서를 확인하지 못하면 잘못된 위치로 계속 넣지 않고 중단합니다.
- 사진 위치가 없는 초안은 앱에서 저장할 때 문단 사이에 위치를 보완합니다.
- 소제목 서식·가운데 정렬 등의 네이버 꾸미기는 완전히 재현하는 기능이 아닙니다.
- 새 기본 분위기는 '밝고 자연스러운 일상 후기체'입니다. 기존 초안의 선택은 유지합니다.
- 기존 글을 새 분위기로 쓰려면 해당 분위기를 선택하고 글 생성을 다시 실행하세요.
